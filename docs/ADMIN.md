# 博客后台使用说明

后台仅支持一个管理员。登录后可查看、搜索、筛选文章，创建草稿，并在 Markdown 源码与可视化模式之间切换。

## 编辑与发布

- Markdown 是唯一真实内容格式；可视化编辑器只编辑其兼容子集。
- 含 MDX 或原生 HTML 的文章会保留在源码模式，避免转换丢失。
- “保存”只写入数据库并生成历史版本；“发布”还会加入 Astro 构建队列。
- 构建、首页校验全部成功后才切换 nginx 的线上目录。失败时线上仍保持上一版本。
- 发布中心可查看数据库修订、线上修订、构建日志摘要和失败重试。

## 图片

编辑器将图片先交给 CMS API 校验，再代理到 EasyImage。图床删除凭据不会下发到浏览器。单张图片最大 10 MiB。

## 本地访问

在配置域名和 HTTPS 前，先建立 SSH 隧道，再打开 `http://127.0.0.1:8790`：

```bash
ssh -L 8790:127.0.0.1:8790 root@39.99.232.157
```

管理员密码、数据库密码均不得写入仓库。忘记密码时由服务器终端执行受控重置，不创建第二个管理员。
